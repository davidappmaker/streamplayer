网络诊断

请先选择一个频道

如果显示「超时」，说明是源服务器连不上（网络不通或源已失效），播放器本身没有问题。可以换一个源，或配置代理重试。

代理设置

某些直播源是 http 地址、或会跳转到没有 CORS 头的服务器，浏览器无法直接读取。这里填一个反向代理地址，播放器会自动把 http 源通过它转发。

电脑本机：双击项目里的「启动本地代理.bat」，保持黑窗口开着，在这里填 http://127.0.0.1:8787/?url=。
手机 / 长期可用：把项目自带的 worker.js 部署到 Cloudflare Workers，填它给出的 https://xxx.workers.dev/?url=。部署说明见 README。

留空则不使用代理。HTTPS 源默认直连，不受影响。

添加到 iPhone 主屏幕

1. 用 Safari 打开本页面（其他浏览器不支持添加到主屏幕）

2. 点击底部中间的「分享」按钮 ⬆

3. 向下滑动，选择「添加到主屏幕」

4. 确认名称后点「添加」，桌面就会出现独立 App 图标

从桌面打开会隐藏浏览器地址栏，全屏使用；频道数据依然保留。
